# Wheel of Fortune (React + Vite)

Pick a number (1–8), choose a bet, spin. Land on your number and win 8× your bet.

## Run
```bash
npm install
npm run dev      # development
npm run build    # production build in /dist
```

Features: animated bulb-lit wheel, tick sounds (WebAudio), confetti, coin balance,
streaks, win rate, recent spins, progress saved in localStorage.
